## 二、 核心对比文献的原版叙事方式拆解（为什么之前的 Abstract 思路不对）

通过逐篇精读上述原版论文的 Abstract 与 Introduction，可以清晰看到该领域顶会论文的标准叙事范式与概念体系：

### 1. 摘要中**绝不直接堆砌裸数学公式**，而是用“成对的核心概念机制”讲清因果链
- 上述 11 篇论文的 Abstract 中，**没有任何一篇**在摘要里直接写 $(1-p(h))^n$、$\Delta_{\mathrm{evo}}(k,B)$ 或 $(p_\theta, 1-p_\theta)$ 这类代数符号。
- 相反，它们全部采用**“任务范式 → 关键失灵模式（命名一个极具画面感的现象） → 双重耦合矛盾拆解 → 核心机制设计 → 实验跃升”**的五步概念叙事：
  - **`AREW` (ICML 2026)**：先定义 *active reasoning*（智能体无法一开始拿到全部信息，必须通过交互获取新观测并更新理解），随即指出标准结果奖励 RL 会陷入 **Information Self-Locking (SeL)**。接着将智能体能力拆解为 **Action Selection (AS，决定观测流质量)** 与 **Belief Tracking (BT，决定证据内化利用)** 两个相互耦合的齿轮：*“weak BT obscures the credit of informative actions, while weak AS deprives BT of useful evidence.”*
  - **`InfoPO` (ICML 2026)**：从多轮交互中的 **“Honorable Failures（光荣失败：前期正确获取了关键信息，仅在最后执行步出错，但在轨迹级 GRPO 下拿到 0 回报）”** 切入，提出用 **可见反馈 vs. 遮蔽反馈的反事实（masked-feedback counterfactual）** 下后续动作分布的变化来度量单轮信息增益。
  - **`GiGPO` (NeurIPS 2025)**：对比单轮数学推理与多轮环境交互，指出多轮稀疏奖励压扁了步骤级差异，提出 **Episode-level Macro Advantage + Anchor-State Step-level Micro Advantage** 的双层群组信用分配，同时保持 critic-free 与低显存优势。
  - **`BB-WM` (2026.09) & `EnvProbe` (2026.10)**：明确区分两类动作——**Pragmatic Actions（直接推进任务目标的执行动作）** 与 **Epistemic Actions（探查环境以消除当前状态不确定性的信息获取动作）**，并指出在有限交互预算下，每次探测都会消耗原本用于任务执行的步数机会（*fundamental trade-off between acquiring information and advancing task execution*）。
  - **`PoS` (2026.10) & `WorldEvolver` (EMNLP 2026)**：均明确定位为 **Inference-time / Deployment-time（推理期/部署期冻结策略参数 $\theta$）** 的外部脚手架：
    - `PoS` 在推理期显式维护结构化信念状态并检测 **Belief Trapping（动作继续但任务进展停滞）**；
    - `WorldEvolver` 在保持下游智能体与世界模型**参数完全冻结**的前提下，通过检索真实转移（Episodic Memory）和从预测-观测失配中提炼规则（Semantic Memory）来演化部署期上下文。

### 2. `PRISM-Evolve` 在该文献坐标系中的真正黄金切入点
将上述文献放在同一个坐标系下，`PRISM-Evolve` 的叙事逻辑立刻变得极其自然、锋利且无懈可击：
1. **研究背景（与 `AREW` / `BB-WM` / `EnvProbe` 同频共振）**：
   长时程工具与环境交互智能体运行在部分可观测与有限交互预算下，必须在 **认知型探测动作（epistemic/information-seeking actions）** 与 **务实型执行动作（pragmatic/task-execution actions）** 之间持续权衡，并将探回的证据内化到后续执行决策中。
2. **现有两大范式的根本困境（精准命中上述每篇代表作的真实边界）**：
   - **推理期外部辅助范式（`PoS`、`EnvProbe`、`WorldEvolver`、`BB-WM`）**：保持策略参数冻结，依赖推理期显式信念维护、外置探测控制器或非参数化文本经验库来修补决策。这不仅在每次测试部署时引入持续的上下文膨胀与多轮控制开销，而且从未真正提升底层策略自身的信息获取与证据利用能力。
   - **训练期多轮强化学习范式（`GiGPO`、`T3`、`AREW`、`InfoPO`）**：虽然尝试通过锚点状态分组（`GiGPO`）、轨迹截断/方向性批评重加权（`T3`/`AREW`）或反事实遮蔽内在奖励（`InfoPO`）改善信用分配，但它们**全部受制于同策略自然采样（natural on-policy group rollouts）**：当处于“信息自锁（information self-locking）”状态的策略在关键决策点极少采样探测动作时，整组采样轨迹中根本不出现信息分支，导致事后信用重分配“巧妇难为无米之炊”；而强行加入轮次级内在信息增益奖励（`InfoPO`）则会篡改预算任务目标，在简单状态诱发过度探测（over-probing）。
3. **`PRISM-Evolve` 的破局之道（对应我们的三大核心技术贡献）**：
   - **从“事后重分配”走向“采样层同前缀分层干预”（Same-Prefix Stratified Rollouts）**：在训练期选定决策前缀处保存环境快照，强制从同一历史与剩余预算下并行展开一条**信息获取分支**与一条**直接执行分支**，正面打破探索饥饿，直接暴露“探测 vs. 执行”的真实反事实效用差。
   - **目标保持的策略更新（Objective-Preserving Policy Update，正面超越 `Step-DPO`）**：强制分层采样改变了分支采样分布，若直接套用无权重的分叉点偏好优化（如 `Step-DPO`）会使策略偏离真实单轨部署目标。我们推导出以策略自身模式门控概率加权的**目标保持更新算子**，严格证明其梯度对真实部署目标无偏，且相比自然同策略采样严格降低了模式选择方差。
   - **跨任务参数自演化与零开销单轨部署（Subspace-Orthogonal Parametric Self-Evolution）**：通过正交低秩适配器将“何时探测”与“如何利用反馈”共同内化到持久策略参数中，测试期无需任何环境回滚、外部信念追踪器或经验检索，以纯单轨策略实现更快、更准的长时程规划。
