# PRISM DCC v2：有限模型机制实验复现包

日期：2026-11-09。

本目录记录实际执行的机制研究，包含源代码、逐种子数据、配对比较及图表。它不包含原生 ALFWorld、WebShop、LOCA 成绩，不包含 7B 模型训练，也没有实现开放语言程序自动生长。

## 复现

运行环境为 Python 3.12.14、NumPy 2.3.5、Matplotlib 3.10.8。代码仅依赖 NumPy；绘图另用 Matplotlib。以下命令在本目录中执行：

```bash
python program_study.py --seeds 512 --fields 4 6 8 --blocks 32
python plot_results.py
```

第一条命令重写 results.json，第二条命令重写图表及 paired_comparisons.json。随机数种子在源码中固定。若先试跑其他参数，请通过 --output 指定另一个结果路径，保留正式结果。

## 两类实验

已知机制诊断使用公平二进制字段。k 个字段的 parity 决定最终行动，其余字段无关。完整读取 k 个相关位的程序、单步 EVSI、随机子集及强制继续的单步 EVSI 分别作精确计算。代码对 8 个 bit、读取 2 个字段的随机策略穷举核对。该部分已知模型关系。

未知机制学习隐藏相关字段对及其极性。n 个字段对应 n(n−1)/2 个两读程序和两倍数量的机制假设。每个训练锚点独立重采样字段；同一个机制跨锚点共享。程序先读两位，再从相同后继快照执行两个行动，四次环境动作形成一个测量块。

正确行动的局部通过率为 0.8，另一行动为 0.2。两个行动共享同一个随机变量，因此联合结果为共同失败 0.2、共同通过 0.2、仅正确行动通过 0.6。完整块的联合 likelihood 用于后验更新；两个分支未被当成独立样本。

代码只模拟短实验及局部部署，完整长任务未实现；完整任务成功标签由协议固定为全零。公开的局部响应提供学习信号。有限假设类、完整两读程序语法、噪声分布和评价目标是所有方法共有的先验。它们未由此次算法学习。

## 比较和指标

四个选择器共享模型和候选池：均匀完整程序、最大预测熵、最大模型信息增益、完整程序 EVSI。后者使用有限假设下的精确公式，不对虚拟结果重训模型。源码内独立以直接后验策略价值和 Bayes regret 复算该公式，并枚举原始四位状态核对联合 likelihood。

每个配置运行 512 个独立种子、32 个测量块。各方法共享每个种子的真实机制和结果随机流，选择随机流与结果流分开。部署决策只读取后验，平局在评价中求均值。真实机制仅用于环境和评价。

指标是新实例上的期望局部响应值，未训练值为 0.5，已知机制上限为 0.8。它不是完整长任务成功率。区间为跨种子均值的 95% 正态近似；配对差区间利用相同 seed 的结果之差。完整程序 EVSI 在 6 候选时低于模型信息增益，此结果保留。

每个测量块计 4 次环境动作。状态创建、快照恢复、程序枚举和模型计算没有包含在这个横轴里。原生任务比较需要分别报告这些成本。

## 文件

program_study.py 为模型、选择器、精确诊断与学习循环；results.json 保存所有检查点和逐种子值；plot_results.py 生成曲线与配对比较；paired_comparisons.json 保存差值及区间；finite_model_results.png 与 finite_model_results.svg 为图表。manifest.json 提供复现参数与文件哈希。压缩包中的 PRISM_research_redesign_DCC.md 是完整研究报告。

## 当前证据的用途

该实验支持继续研究公开响应学习、互补程序和有限预算下的决策采集。开放语言候选生成、行动差驱动程序切片/拼接、未知噪声规律和原生长任务仍属于研究设计中明确定义的后续实验。此次有限类实验不承担这些结果。
